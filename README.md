# os_info
# Скрипт сбора системной информации

Этот скрипт собирает подробные данные об операционной системе, аппаратной конфигурации компьютера и используемом окружении Python, после чего сохраняет их в JSON-файл.

## Описание работы

1. **Инициализация:** Скрипт запускается и обращается к встроенным библиотекам `os`, `json` и `platform`.
2. **Сбор базовых данных:** Формируется словарь с универсальными характеристиками системы, актуальными для любой ОС (архитектура, данные процессора, версия Python и т.д.).
3. **Проверка ОС и расширенный сбор:** Скрипт определяет текущую операционную систему и дополняет словарь специфичными параметрами:
   - Для **Windows**: собираются редакция, версия и путь к системной директории `AppData`.
   - Для **Linux**: определяется точное название дистрибутива.
4. **Экспорт данных:** Собранная информация упаковывается в финальный JSON-объект и записывается в файл `system_info.json` в корневой директории скрипта (с сохранением кириллицы и форматированием отступами в 2 пробела).
5. **Уведомление:** В консоль выводится сообщение об успешном сохранении файла.

## Собираемые параметры

### 1. Общая системная информация
* **os_type**: Название операционной системы (например, `Windows`, `Linux`).
* **os_release**: Релиз операционной системы.
* **os_version**: Полная версия операционной системы.
* **machine**: Аппаратная платформа (например, `AMD64`, `x86_64`).
* **processor**: Название и семейство процессора.
* **architecture**: Архитектура системы (битность и формат исполняемых файлов).
* **cpu_cores**: Количество доступных логических ядер процессора.
* **hostname**: Сетевое имя компьютера (имя узла).

### 2. Информация об окружении Python
* **python_version**: Версия интерпретатора Python.
* **implementation**: Реализация Python (например, `CPython`).
* **compiler**: Компилятор, использованный для сборки Python.
* **build**: Номер и дата сборки Python.

### 3. Специфичные параметры для Windows
* **win_edition**: Редакция ОС (например, `Professional`, `Home`).
* **win_ver_tuple**: Кортеж с подробными версионными данными Windows.
* **appdata_path**: Путь к папке приложений `AppData` текущего пользователя.

### 4. Специфичные параметры для Linux
* **linux_distribution**: Название дистрибутива Linux (например, `Ubuntu`, `Debian`, `Fedora`).
